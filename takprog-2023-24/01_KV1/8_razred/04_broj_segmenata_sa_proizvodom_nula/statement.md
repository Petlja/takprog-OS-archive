*Аутор: Милан Вугделија*

Написати програм који за дати низ целих бројева одређује број сегмената (поднизова са 
узастопним елементима) датог низа, којима је производ елемената једнак нули.

## Улаз

У првом реду стандардног улаза је број $n$ $(1 \leq n \leq 100000)$, број елемената низа.
У другом реду је $n$ целих бројева из интервала $[-100 ,100]$ раздвојених по једним 
размаком, елементи низа.

## Излаз

На стандардни излаз исписати један цео број, тражени број сегмената.

## Пример 1

### Улаз

~~~
5
1 2 3 0 5
~~~

### Излаз

~~~
8
~~~

### Објашњење

То су сегменти ``1 2 3 0``, ``1 2 3 0 5``, ``2 3 0``, ``2 3 0 5``, ``3 0``, ``3 0 5``, 
``0``, ``0 5``.


## Пример 2

### Улаз

~~~
3
0 1 0
~~~

### Излаз

~~~
5
~~~

### Објашњење

То су сегменти ``0`` (прва нула), ``0 1``, ``0 1 0``, ``1 0``, ``0`` (друга нула).
