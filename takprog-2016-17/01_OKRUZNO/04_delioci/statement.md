Niz brojeva se dobija na sledeći način: počinje se od nekog zadatog broja i svaki naredni broj se dobija tako što se prethodnom broju doda broj svih njegovih delilaca. Na primer, ako je neki član niza jednak $6$, onda je sledeći član niza jednak $6 + 4$ tj. $10$, jer postoje $4$ delioca broja $6$ (to su redom brojevi $1$, $2$, $3$, $6$).

## Ulaz

U prvom redu standardnog ulaza se nalazi prvi član niza ($0 < a1 \leq
10000$) i u drugom redu prirodan broj $N$ ($0 < N \leq 100$).

## Izlaz

Na standardni izlaz se štampa $N$-ti član niza $a_N$.

## Primer 1

### Ulaz

```
2
5
```

### Izlaz

```
12
```

## Primer 2

### Ulaz

```
1
100
```

### Izlaz

```
744
```
