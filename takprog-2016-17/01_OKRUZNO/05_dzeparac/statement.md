Nađa je od oca svaki dan tokom jedne radne nedelje dobijala džeparac. Napiši program koji određuje kog dana je dobila najveći džeparac i koliko je taj džeparc iznosio.

## Ulaz

Program sa standardnog ulaza učitava pet prirodnih brojeva, svaki u posebnom redu (džeparac za ponedeljak, utorak, sredu, četvrtak i petak, redom).

## Izlaz

Program na standardni izlaz ispisuje traženi dan označen tekstom `pon`, `uto`, `sre`, `cet`, `pet` i nakon toga iznos džeparca odvojen jednim razmakom.

## Primer 1

### Ulaz

```
135
220
175
80
200
```

### Izlaz

```
uto 220
```

## Primer 2

### Ulaz

```
110
180
105
240
225
```

### Izlaz

```
cet 240
```
