Дат је низ позитивних целих бројева $A_1, A_2, \ldots, A_N$. *Вредност* неког подниза $A_L, A_{L+1}, \ldots, A_R$ ($1 \leq L \leq R \leq N$) се дефинише као

<div align="center">
$$A_L + (A_R \oplus \text{NZD}(A_L, A_{L+1}, \ldots, A_R)).$$
</div>

Овде $\text{NZD}$ за $L < R$ означава највећи заједнички делилац бројева $A_L, A_{L+1}, \ldots, A_R$, док за $L=R$ има вредност $A_L$. Са $\oplus$ је означена операција ексклузивне дисјункције (xor) два броја. За детаље видети напомену на крају задатка.

Међу вредностима свих поднизова низа $A$, одредити највећу од њих.

## Улаз

У првом реду стандардног улаза налазе се један цео број - $N$ који представља број елемената низа.

У другом реду стандардног улаза је $N$ целих бројева који представљају елементе низа $A$.


Пошто је велика количина података на улазу, препоручује се коришћење
```
ios_base::sync_with_stdio(false);
cin.tie(NULL);
```
или функција `scanf` и `printf`.

## Излаз

На стандардном излазу исписати један цео број који представља тражени број.


## Додатна ограничења

- $1 \leq N \leq 10^5$
- $1 \leq A_i \leq 10^{18}$ за $1 \leq i \leq N$

Tест примери су подељени у 6 група:

- у тест примерима вредним $7$ поена важи $N \leq 1000$;
- у тест примерима вредним $16$ поена важи $A_i \leq 20$ за $1 \leq i \leq N$;
- у тест примерима вредним $23$ поена важи $A_i$ је степен тројке за $1 \leq i \leq N$;
- у тест примерима вредним $16$ поена важи $A_i \leq 10^5$ за $1 \leq i \leq N$;
- у тест примерима вредним $14$ поена важи $A_i \leq 10^7$ за $1 \leq i \leq N$;
- у тест примерима вредним $24$ поена нема додатних ограничења.

## Пример 1

### Улаз

~~~
3
70 42 30
~~~

### Излаз

~~~
106
~~~

### Објашњење примера
Имамо 6 поднизова:
- подниз $[70]$: $\text{NZD(70)} = 70$, вредност $= 70 + (70 \oplus 70) = 70 + 0 = 70$;
- подниз $[42]$: $\text{NZD(42)} = 42$, вредност $= 42 + (42 \oplus 42) = 42 + 0 = 42$;
- подниз $[30]$: $\text{NZD(30)} = 30$, вредност $= 30 + (30 \oplus 30) = 30 + 0 = 30$;
- подниз $[70, 42]$: $\text{NZD(70, 42)} = 14$, вредност $= 70 + (42 \oplus 14) = 70 + 36 = 106$;
- подниз $[42, 30]$: $\text{NZD(42, 30)} = 6$, вредност $= 42 + (30 \oplus 6) = 42 + 24 = 66$;
- подниз $[70, 42, 30]$: $\text{NZD(70, 42, 30)} = 2$, вредност $= 70 + (30 \oplus 2) = 70 + 28 = 98$.

Међу вредностима свих поднизова ($70, 42, 30, 106, 66, 98$), највећи број је $106$.

## Напомена
Оператор ексклузивне дисјункције у C++ записујемо помоћу симбола `^`. Ова операција $x \oplus y$ се за ненегативне целе бројеве $x, y$ дефинише на следећи начин. Прво се бројеви запишу у бинарном запису. Уколико један број има мање бинарних цифара од другог, дописују му се водеће нуле све док не буду имали исти број бинарних цифара. Тако се добијају два низа бинарних цифара, означимо их са $a_1, \ldots, a_k$ и $b_1, \ldots, b_k$. Затим се за сваку позицију $i \in \{1, \ldots, k\}$ рачуна $c_i$ помоћу следећих правила:
- За $a_i = 0, b_i = 0$ важи $c_i = 0$,
- За $a_i = 0, b_i = 1$ важи $c_i = 1$,
- За $a_i = 1, b_i = 0$ важи $c_i = 1$,
- За $a_i = 1, b_i = 1$ важи $c_i = 0$.

Низ бинарних цифара $c_1, \ldots, c_k$ (који можда има водеће нуле) је бинарни запис резултата, односно броја $x \oplus y$.
