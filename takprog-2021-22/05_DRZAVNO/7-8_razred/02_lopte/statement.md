Непомична камера снима из висине неколико лопти које се котрљају. Свака слика 
са те камере се састоји од $m$ врста и $n$ колона. За сваку лопту је познат 
почетни положај на слици и брзина кретања. Написати програм који одређује положај 
лопти на слици након одређеног броја секунди (неке лопте могу и да изађу ван 
слике и њих не треба приказивати). Могуће сударе лопти занемарити, тј. рачунати као 
да лопте пролазе једна кроз другу.


## Улаз

Са стандардног улаза се учитавају димензије слике $m$ и $n$ ($1 \leq m,
n \leq 100$), након тога број секунди $k$ ($0 \leq k \leq 100$)и након
тога, до краја стандардног улаза линије које садрже по четири броја: $v$ 
и $k$ ($0 \leq v < m$, $0 \leq k < n$) означавају редни број врсте и
колоне на којој се лопта налази у почетном тренутку, а $v_v$ и $v_k$ 
($-3 \leq v_v, v_k \leq 3$) означавају брзину кретања лотпе по врстама 
и по колонама (у свакој секунди врста се промени за $v_v$, а колона за 
$v_k$). 

## Излаз

На стандардни излаз исписати положај сваке лопте након $K$ секунди
(празна пољa означити карактерима `.` а поља на којима је лопта
карактером `#`).

## Пример

### Улаз

~~~
6 7
1
1 1 0 1
1 2 1 0
1 3 -1 0
1 4 1 0
1 5 0 -1
3 0 0 1
3 2 0 0
3 3 0 0 
3 4 0 0
3 6 0 -1
5 2 -1 -1
5 4 -1 1
5 1 0 0
5 5 0 0
~~~

### Излаз

~~~
...#...
..#.#..
..#.#..
.#####.
.#...#.
.#...#.
~~~

### Објашњење

Положај лопти на почетку је 

~~~
.......
.#####.
.......
#.###.#
.......
.##.##.
~~~

Када се лопте помере на начин како то њихове брзине описују добије се
приказ великог слова `A`.
